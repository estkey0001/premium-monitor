# DESIGN SYSTEM（デザインのルール）

現状（`CURRENT_UI_AUDIT.md` 5章）: 色229種類、文字サイズ48種類、角丸17種類、ボタンのクラス29種類、ブレークポイント6種類。
新しい画面ではこれを下の数に絞る。旧画面は段階Fまでそのまま残す。

## 1. 色

### 1.1 意味のある色（5つ）

| 色 | 意味 | 使う場所 | 文字色 / 背景色（案） |
|---|---|---|---|
| 赤 | 急ぎ・締切間近 | 締切間近、今日締切 | `#b91c1c` / `#fef2f2` |
| 橙 | 注意・まもなく開始 | まもなく開始、日程要確認、WAIT | `#b45309` / `#fffbeb` |
| 緑 | 応募できる・買える | 受付中、販売中、APPLY、BUY、検証済みの利益 | `#047857` / `#ecfdf5` |
| 青 | 情報 | 結果待ち、当選発表・購入期間、発売予定、高プレミア | `#1d4ed8` / `#eff6ff` |
| 灰 | 終了・動きなし | 終了、0件、SKIP、参考 | `#475569` / `#f1f5f9` |

- 意味の色は**状態を表すときだけ**使う。装飾に使わない
- 色だけで伝えない。必ず文言（「受付中」など）と一緒に出す
- 文字と背景のコントラストは 4.5:1 以上

### 1.2 基本の色

| トークン | 用途 |
|---|---|
| `--ink` / `--ink2` / `--ink3` | 本文／補足／薄い補足 |
| `--bg` / `--card-bg` / `--card-border` | ページ背景／カード／枠線 |
| `--brand` | ロゴ・選択中のナビ（1色だけ） |

既存の68個のCSS変数のうち、上に当たるものはそのまま使う。

## 2. 文字

実装: `src/content/ui/design_tokens.py` の `FONT_SIZES`（CSS では `--font-xs`〜`--font-xxl`）。

| 名前 | サイズ | 用途 |
|---|---|---|
| xs | 12px | 注記・バッジ・タイルの見出し（これより小さくしない） |
| sm | 14px | 販売店・日時・補足 |
| md | 16px | 本文・カードの商品名・ボタン |
| lg | 20px | 画面の見出し・カードの主な数字 |
| xl | 24px | タイルの件数 |
| xxl | 32px | 予備 |

数字（価格・件数・カウントダウン）は `font-variant-numeric: tabular-nums`。

## 3. 余白・角丸・影

- 余白: 4 / 8 / 12 / 16 / 24 / 32 / 48px の7段階（`--space-1`〜`--space-7`）
- 角丸: 8px（ボタン・小さな枠）、12px（カード・タイル）、16px（予備）。チップ・バッジだけ 999px
- 影: カードに1種類だけ（`--shadow`）。重ねない

## 4. 部品

### 4.1 状態バッジ

- 1カードに1つ
- 文言と色は `NEW_INFORMATION_ARCHITECTURE.md` 9章の対応表だけを使う（`status → {文言, 色}` の対応を1か所に置く）

### 4.2 ボタン

| 種類 | 見た目 | 決まり |
|---|---|---|
| メイン | 塗りつぶし（意味の色） | **1カードに1つ**。高さ44px以上、横幅いっぱい（モバイル） |
| サブ | 枠線だけ | 1画面に少しだけ |
| 文字リンク | 下線 | カード内の補足リンク |

ボタンのクラスは `nu-btn` / `nu-btn--primary` / `nu-btn--secondary` / `nu-btn--link` の4つ（新UIは `nu-` で始まるクラスだけを使い、旧UIのクラスと混ぜない）。

### 4.3 カード

- 中身の順番: 商品名 → 販売店 → 状態と価格 → 日時 → ボタン → 開閉（1つまで）
- 開閉（`<details>`）は入れ子にしない

### 4.4 空状態

「無い理由」と「次に起きること（または代わりにできること）」を必ず1組で出す。

| 悪い例 | 良い例 |
|---|---|
| 現在、十分な自動取得データがありません | 今受付中の抽選はありません。次の予定: ワンピース ○○（10/5 開始） |
| 0件 | 今、確実に利益が出る商品はありません。参考情報が1件あります |

### 4.5 表

- 640px以上: 表
- 640px未満: 1行を1枚のカードにする（項目名: 値 の縦並び）

## 5. レイアウト

- ブレークポイントは2つだけ: **640px**（モバイル/タブレット）と **900px**（2列）
- 中身の最大幅 1120px（今と同じ）
- モバイルの左右の余白 16px。ページ全体の横はみ出しは0
- タップ対象は44×44px以上。タップ対象どうしの間は8px以上
- ボトムナビは下に固定、高さ56px、iPhoneの下部の安全領域を空ける

## 6. 情報の量

- 1カードに出す項目は6つまで（残りは開閉の中）
- 1画面（モバイル）に出すカードは2〜3枚
- グループの最初に出すのは5件まで。残りは「もっと見る（n件）」
- 同じ注意書きを繰り返さない（ページの下に1回だけ）
