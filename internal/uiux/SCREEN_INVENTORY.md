# SCREEN INVENTORY（画面一覧）

新しい構成で作る画面と、それぞれの中身・元データ・状態。

| ID | 画面 | URL（案） | 対象ユーザー | 元データ（既存） | 移行段階 |
|---|---|---|---|---|---|
| S1 | HOME | `/` | A〜F | TCG判定結果、利益ルート、AI Opportunities exports、前日差分 | B |
| S2 | 抽選・販売 | `/#lottery` | A, B | TCG抽選（`src/tcg/lottery`）、TCG販売イベント、旧来の抽選 | C |
| S3 | 抽選の詳細（カードを開いた状態） | 同上（`<details>`） | A | 応募条件原文、支払い方法、購入期間、confidence、情報源 | C |
| S4 | 利益商品 | `/#profit` | C, D | 差益ランキング、せどりルート、初心者・Pro の商品データ | D |
| S5 | 商品検索 | `/#search` | E | 全商品カタログ、ジャンル・メーカー | D |
| S6 | 商品詳細 | `/#product-<id>`（既存の `product-*` id を流用） | D, E | 買取店比較、海外相場、抽選・販売、価格推移 | D |
| S7 | マイページ | `/#me` | C〜F | 表示モード、通知導線、`/beta/` の中身 | B |
| S8 | 管理画面 | `/admin/` | G | Health、Source Health、collector_report、exports | E |
| S9 | 過去のLP | `/archive/` | F | 既存 | 変更なし |

※ 静的な1ページ構成を続けるか、ページを分けるかは `MIGRATION_PLAN.md` 3章。初期案は「一般向けは1ページ＋ハッシュで切り替え、`/admin/` だけ別ページ」。

## S1 HOME

| ブロック | 中身 | 空のとき |
|---|---|---|
| ヘッダー | ロゴ、最終更新日時、表示モード切り替え | — |
| 今日のチャンス | 6タイル（抽選受付中／今日締切／24時間以内に開始／今買える／高プレミア／高利益） | 0件タイルは灰色＋次の予定 |
| おすすめアクション TOP5 | APPLY / BUY / WAIT / SKIP | 「今日すぐやることはありません。次の予定: …」 |
| 前回からの変化 | 新規受付・締切・値動き | 「前回から変化はありません」 |
| 情報の状態（1行） | 「一部の情報源が取得できていません（詳しく）」 | 全部正常なら出さない |
| フッター | 免責、アーカイブ、通知、管理画面への小さなリンク | — |

## S2 抽選・販売

| ブロック | 中身 |
|---|---|
| フィルタ | すべて／ポケカ／ワンピース／カメラ／ゲーム機 |
| 件数チップ | 受付中・締切間近・まもなく開始・当選発表… を押すとその見出しへ移動 |
| 1〜5 抽選グループ | 抽選カード（S3） |
| 6〜10 販売グループ | 販売カード（今買える／コンビニ／再販／BOX／プレミア） |
| 過去の抽選 | 終了したもの（畳む） |
| 監視範囲の注記 | 「公式サイト17か所を監視」＋取得できていない所があれば1行 |

## S3 抽選カード

| 表示 | 項目 |
|---|---|
| いつも | 商品名、販売店、状態、締切（カウントダウン）、価格、ボタン1つ |
| 開いたとき | 応募条件、支払い方法、購入期間、当選発表日、シュリンク、確かさ、情報源、最終確認日時 |

## S4 利益商品

| ブロック | 中身 |
|---|---|
| タブ | おすすめ／高ROI／高利益額／高回転／低リスク |
| 絞り込み | ジャンル |
| 検証済みの一覧 | 利益カード（かんたん/詳細で項目が変わる） |
| 参考（未検証） | 参考ルート。理由（eBay未設定、データが古い等）を1行で |
| 0件のとき | 「今、確実に利益が出る商品はありません。参考情報: n件」 |

## S5 商品検索

| ブロック | 中身 |
|---|---|
| ジャンル | TCG／iPhone・スマホ／PC・タブレット／カメラ／ゲーム機／その他 |
| 絞り込み | メーカー、抽選あり、今買える、利益あり、監視中 |
| 結果 | 商品カード → S6 |

## S6 商品詳細

公式価格、抽選・販売の状況、買取店比較（全店）、海外相場、利益の計算（手数料込み）、データの確かさと取得日時。

## S7 マイページ

表示モード、通知の案内、はじめかた、情報の見方、免責。

## S8 管理画面（`/admin/`）

| セクション | 中身 |
|---|---|
| 概要 | Health Score、deploy-check の結果、最終実行 |
| Source Health | 監視元ごとの状態（ACTIVE_LOTTERY / NO_ACTIVE_LOTTERY / SOURCE_BLOCKED / SOURCE_UNREACHABLE / SOURCE_NOT_MONITORED / SOURCE_DEGRADED / SOURCE_FAILED） |
| API Health | eBay canary などの結果 |
| Collector Errors | 取得失敗一覧（collector_report の中身） |
| Data Quality | 0円率、stale率、suspicious_price、異常値として一般表示から外したもの |
| Blocked / Rate Limit / Circuit Breaker | 取得制限の状況 |
| Execution diagnostics | 実行計画、週次振り返り |
| 運用メモ | eBay API の有効化方法、改善優先順位 |

`noindex`、`robots.txt` で除外、一般ナビに出さない。

## 共通部品

| 部品 | 使う画面 | 決まりごと |

| 表 | S4（詳細）, S6, S8 | 640px未満ではカード表示に変える |
